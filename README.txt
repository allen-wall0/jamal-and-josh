JOSH AND DOUG 3D, GOTY EDITION (Phase 2)

Host: upload every file and folder to the root of a static host such as GitHub Pages. Open index.html.
Core levels: Street, Warehouse, Yard, Rail Yard, Control Facility (plus the Wesker bonus fight).
New sections: The Perimeter (stealth, after the Warehouse) and The Escape (vehicle chase, after the Yard). QTEs appear in the intro, when Doug is grabbed, and during stealth takedowns.
Controls: WASD move, Shift sprint, Space jump, C crouch, right-click aim, click fire, R reload, 1/2/3 weapons, Q focus, P photo mode, Esc pause, E shove / takedown, F box (stealth), G throw can (stealth).
Driving: W/S throttle and brake, A/D steer, Space handbrake drift, Shift boost.
Options: graphics preset, brightness, interface size, QTE assist (longer windows or auto-succeed). If the screen is black add ?gfx=retro to the URL.
