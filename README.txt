Jamal Ismail 5.0 (8 realms + random environment effects, Josh Stone pages, sprint+jump, hunting watchers, scream; Void, Alien Forest, Fall, Drowning, Death cycles). Replace your repo contents with these files, push, enable GitHub Pages (Settings > Pages > main branch).
Lore text is at the top of app.js. Realms are listed at the top of world.js.
The 3D world uses JavaScript modules: it works on GitHub Pages (https) but not by double-clicking index.html. To test locally run: python3 -m http.server  then open http://localhost:8000
After hosting, set og:image in index.html to the full https URL of jamal.webp.
