JOSH AND DOUG 3D, GOTY EDITION (Phase 1.5 + 1.6)

How to host: upload every file and folder in this zip to the root of a static host such as GitHub Pages. Open index.html.
Controls: WASD move, Shift sprint, Space jump, C crouch, right-click aim, click fire, R reload, 1/2/3 weapons, Q focus, P photo mode, Esc pause.
Graphics: Auto by default (next-gen renderer). Options menu has Ultra/High/Medium/Low/Retro PS1 and a Brightness slider. If the screen is black, add ?gfx=retro to the page URL.
Music: tracks live in the music folder (level1-5, bonus-wesker, three credits tracks).
This build removed the old Jamal pages and Jamal 3D game. Older versions remain in your earlier zips.
